# Bluetooth-based-Home-Automation-System
MINI PROJECT
TITLE: BLUETOOTH BASED HOME AUTOMATION SYSTEM
INTRODUCTION:
 A Bluetooth-Based Home Automation System is a smart control system that allows users to 
operate electrical appliances such as lights, fans using a Bluetooth-enabled smartphone. The system 
provides wireless control over home appliances, improving convenience and reducing the need for 
manual operation. It offers a low-cost and efficient solution for basic home automation.
OBJECTIVE:
 The objective of this project is to design and develop a Bluetooth-based wireless home 
automation system that enables users to control household appliances such as bulbs and fans through a 
smartphone application. The system aims to provide a simple, reliable, cost-effective, and user￾friendly solution for home automation, reducing manual effort while improving convenience and 
accessibility in the operation of electrical devices.
COMPONENT:
• ARM7(LPC2129) Microcontroller.
• Bluetooth Module (HC-05).
• Relay.
• Electrical Load (Bulb/Fan).
• Power Supply Unit.
TOOLS:
• Keil uVision4. 
• Serial Bluetooth Terminal Application.
FLOW DIAGRAM:
Serial Bluetooth Terminal -> Bluetooth Module(HC-05) -> ARM7 Microcontroller(LPC2129) -> Relay -> Electrical Load(Fan/Bulb).
WORKING:
 The Bluetooth-Based Home Automation System operates by establishing wireless 
communication between a smartphone and a microcontroller through a Bluetooth module. The user 
sends ON/OFF commands using a Bluetooth control application on the smartphone, which are 
received by the HC-05 Bluetooth module. The microcontroller processes the received commands and 
accordingly activates or deactivates the relay connected to the appliance. The relay acts as an 
electronic switch that controls the power supply to devices such as bulbs and fans, enabling them to 
turn ON or OFF based on the user's command.
ADVANTAGE:
• Wireless control of appliances. 
• Easy to install and operate. 
• Low power consumption. 
• Cost-effective implementation. 
• Reduces manual effort. 
• Improves convenience and comfort. 
• Compact and reliable system. 
• Can be expanded to control multiple devices.
APPLICATION:
• Smart homes. 
• Home lighting control systems.
• Offices and conference rooms. 
• Hostels and dormitories.
• Remote switching of electrical devices within Bluetooth range.
CONCLUSION:
 The Bluetooth-Based Home Automation System provides a simple and effective way to 
control household appliances wirelessly using a smartphone. It improves user convenience and 
reduces manual effort in operating electrical devices. The project demonstrates the practical 
application of Bluetooth technology and serves as a useful solution for basic home automation.
